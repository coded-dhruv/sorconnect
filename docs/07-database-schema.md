# 07. Database Architecture & Schema Documentation

## 1. Overview & Cloud Infrastructure

The Sor Connect database layer is provisioned on **Supabase**, an enterprise-grade cloud PostgreSQL platform with automated scaling, connection pooling, and continuous point-in-time backups.

- **Database Engine:** PostgreSQL 15.x / 16.x
- **Access Interfaces:**
  - **PostgREST API (v1):** Direct RESTful HTTPS interface (`https://znjpzipedsowuyrpotgb.supabase.co/rest/v1/*`)
  - **Storage API (v1):** S3-compatible cloud object storage (`https://znjpzipedsowuyrpotgb.supabase.co/storage/v1/*`)
  - **Direct PostgreSQL Connection:** Standard TCP connection via PgBouncer port 6543 / 5432.
- **Security Paradigm:** Row-Level Security (RLS) enforced at the PostgreSQL kernel level.

## 2. Relational Entity Overview & Foreign Key Relationships

| Primary Entity Table | Related Foreign Table | Relationship Type | Join Key / Reference | Business Purpose |
|---|---|---|---|---|
| `public.categories` | `public.projects` | 1-to-Many (`1 : N`) | `projects.category_id &rarr; categories.id` | Groups solar installations into commercial, rooftop, utility, or KUSUM categories. |
| `public.submissions` | *(Standalone Table)* | Independent Ingestion | `submissions.id` (PK) | Stores inbound commercial customer inquiries from website forms. |
| `public.careers` | *(Standalone Table)* | Independent Ingestion | `careers.id` (PK) | Stores job applications and links to resume files in Supabase Storage. |
| `public.about_gallery` | *(Standalone Table)* | Sequential List | Ordered by `display_order ASC` | Feeds the interactive plant slider on the About Us page. |
| `public.awards` | *(Standalone Table)* | Sequential List | Ordered by `display_order ASC` | Feeds certifications, green badges, and awards on About and Home pages. |
| `public.services` | *(Standalone Table)* | Ordered Catalog | Ordered by `display_order ASC` | Powers dynamic service cards on `/services` and quotation modals. |
| `public.partners` | *(Standalone Table)* | Brand Directory | Ordered by `display_order ASC` | Displays technology partners (Sungrow, Reliance, Waree, etc.). |

### 3.1 Table: `public.categories`
*Classifies commercial, industrial, and agricultural solar projects.*

| Column | Data Type | Constraints / Defaults | Description |
|---|---|---|---|
| `id` | `BIGINT` | `GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Unique category identifier |
| `name` | `TEXT` | `NOT NULL` | Human-readable name (e.g. `Commercial Rooftop EPC`) |
| `slug` | `TEXT` | `NOT NULL UNIQUE` | URL-safe slug used for client filtering (e.g. `epc`) |
| `description`| `TEXT` | `NULL` | Optional internal or public sector overview |
| `created_at` | `TIMESTAMPTZ` | `DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL` | Record creation timestamp |

- **Indexes:** `CREATE INDEX IF NOT EXISTS idx_categories_slug ON public.categories(slug);`

## 4. Row-Level Security (RLS) Policies

All tables have Row-Level Security explicitly enabled (`ALTER TABLE ... ENABLE ROW LEVEL SECURITY;`).

```sql
-- Read Access: Open to public visitors so websites can fetch data directly
CREATE POLICY "Public can view projects" ON public.projects FOR SELECT USING (true);
CREATE POLICY "Public can view categories" ON public.categories FOR SELECT USING (true);
CREATE POLICY "Public can view gallery" ON public.about_gallery FOR SELECT USING (true);
CREATE POLICY "Public can view awards" ON public.awards FOR SELECT USING (true);
CREATE POLICY "Public can view services" ON public.services FOR SELECT USING (true);
CREATE POLICY "Public can view partners" ON public.partners FOR SELECT USING (true);

-- Lead & Career Insertion: Public visitors can insert new inquiries and applications
CREATE POLICY "Public can insert submissions" ON public.submissions FOR INSERT WITH CHECK (true);
CREATE POLICY "Public can insert careers" ON public.careers FOR INSERT WITH CHECK (true);

-- Admin Full Access: Authorized client operations
CREATE POLICY "Full access to projects" ON public.projects FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Full access to submissions" ON public.submissions FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Full access to careers" ON public.careers FOR ALL USING (true) WITH CHECK (true);
```

## 5. Storage Buckets (`storage.buckets`)

The platform provisions a dedicated, public cloud object storage bucket named **`uploads`**:
- **Bucket ID:** `'uploads'`
- **Public Visibility:** `true`
- **File Size Limit:** `10,485,760 bytes` (10 Megabytes)
- **Allowed MIME Types:** 
  - `image/png`, `image/jpeg`, `image/jpg`, `image/webp`, `image/svg+xml`
  - `application/pdf`, `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
- **Storage Policies:**
  - `Public Access to uploads` (`FOR SELECT USING (bucket_id = 'uploads')`)
  - `Allow uploads into uploads bucket` (`FOR INSERT WITH CHECK (bucket_id = 'uploads')`)
  - `Allow updates to uploads bucket` (`FOR UPDATE USING (bucket_id = 'uploads')`)
  - `Allow deletes in uploads bucket` (`FOR DELETE USING (bucket_id = 'uploads')`)
